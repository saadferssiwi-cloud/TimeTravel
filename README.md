# ⏳ TimeTravel Agency — Interactive Web Application

TimeTravel Agency est une webapp immersive de voyage temporel permettant aux utilisateurs d'explorer différentes époques historiques et préhistoriques à travers une expérience moderne, interactive et alimentée par l'intelligence artificielle.

## 🌐 Live Demo

Déploiement Vercel :

https://time-travel-mu.vercel.app/

## 💻 GitHub Repository

Code source :

https://github.com/saadferssiwi-cloud/TimeTravel.git

---

# 📖 Description du Projet

Cette application a été réalisée dans le cadre d'un projet pédagogique autour du développement web moderne et de l'intégration d'outils d'IA générative.

L'objectif est de proposer une plateforme fictive de voyage temporel permettant aux visiteurs de :

* Découvrir plusieurs destinations temporelles
* Explorer des époques historiques emblématiques
* Interagir avec un assistant virtuel
* Personnaliser leur expérience
* Réserver un voyage temporel

# ⚙️ Installation Locale

Cloner le projet :

```bash
git clone https://github.com/saadferssiwi-cloud/TimeTravel.git
```

Accéder au dossier :

```bash
cd TimeTravel
```

Installer les dépendances :

```bash
npm install
```

Lancer le projet :

```bash
npm run dev
```
